# CHANGELOG.md 2.1.290〜2.1.296

## 要点

- 6日間で7版。中心は **mods（プラグインの深い挙動変更）API の拡充**、**Claude apps gateway の機能追加**、**MCP プロトコル 2026-07-28 の既定化**、**Claude Haiku 5.5 の追加（2.1.293）**。
- サブエージェントまわりの制御が増えた（Agent ツールの `effort`、frontmatter の `autoCompactWindow`、`skills` の先読みは最大32件、workflow エージェント用のモデル指定）。
- フックの失敗時の挙動を選べる `onFailure: "block"` が追加された（2.1.295）。
- セキュリティ関連の修正: UNC パスからの読み込みで許可の確認が飛ばされていた問題（2.1.292）、`BASH_ARGV0` を使うコマンドの自動承認、UTF-8 でないファイルの Edit で文字が壊れる問題、Windows の Git Bash で `rm -rf` に確認が出なかった問題（2.1.296）。
- 設定の安全性の強化: プロジェクトの設定ファイルから Claude in Chrome を有効化できなくなり、`CLAUDE_CODE_DISABLE_ATTACHMENTS` もリポジトリの設定では指定できなくなった（2.1.290）。
- WebSearch の回数上限が「200回で終了」から「1時間に100回ずつ補充」に変わった（2.1.290）。

### 2.1.296
- `managed.policies[]` に `code` キーを追加（Claude apps gateway）。`cli` と同じ設定が Claude Desktop の Code タブにも効く。
- サブエージェントの frontmatter と `--agents` に `autoCompactWindow` を追加。
- `CLAUDE_CODE_WORKFLOW_SUBAGENT_MODEL`（workflow エージェントのモデルを一括指定）。
- `CLAUDE_CODE_OVERLOADED_RETRY_MAX_DELAY_MS`（529 の再試行で待つ時間の上限）。
- Read ツールに `allow_large`。
- MCP のツール説明とサーバー指示を最初に送る量の上限を 2,048 字から 4,096 字に変更。
- Sonnet 5.5 のキャッシュ読み取り単価の計算を $0.20 から $0.10（100万トークンあたり）に変更（`/cost`、ステータスライン、`--max-budget-usd`、SDK）。
- `←`: バックグラウンドへ移すときに始まったターンや `!` コマンドを、見えないところで最後まで走らせず停止するよう変更。
- [VSCode] Claude in Chrome がすべてのセッションでブラウザ操作の前に確認するよう変更。
- セキュリティ: `BASH_ARGV0` を代入して使うコマンドが自動承認されていた問題を修正。UTF-8 でないファイル（Windows-1252、Shift-JIS、GBK）を Edit／NotebookEdit すると非 ASCII 文字が置き換わっていた問題を修正（こうした編集は拒否されるようになった）。Windows の Git Bash で `rm -rf /c/Users/<name>` に bypass モードで確認が出なかった問題を修正。
- managed settings の `PreToolUse` フックが `"continue": false` で拒否してもターンが終わらなかった問題を修正。

### 2.1.295
- コマンドフックと HTTP フックに `onFailure: "block"`。起動しない・タイムアウト・想定外の終了コードのときに、素通りさせず操作を止める。
- Program Status Protocol（OSC 7501）に対応。
- `CLAUDE_CODE_RETRY_WATCHDOG_MAX_WAIT_MS`（`CLAUDE_CODE_RETRY_WATCHDOG` が 429／529 を待つ時間の上限）。
- mods: `$.ui.notify` を追加、`Button` に子要素を追加。
- Claude apps gateway: 上流ごとの `models` リスト、`timeouts.upstream_ttfb_ms`、`forceLoginMethod: "gateway"`／`forceLoginGatewayUrl` のユーザー設定での利用、`upstream_request_id`、`request-id` ヘッダー。Bedrock では CountTokens API を使う（`bedrock:CountTokens` の権限が必要）。
- tool search 経由で読み込む MCP ツール説明の上限を 2,048 字から 16,384 字に変更。
- サブエージェントの `skills` から先読みするのは最大32件。
- claude.ai コネクタも、フラグを取得しない環境では MCP プロトコル 2026-07-28 を既定でネゴシエーションするよう変更。`MCP_PROTOCOL_NEGOTIATION=legacy` で元に戻せる。
- WebSocket（`ws`）の MCP サーバーで 16 MiB を超えるメッセージを受け取ると接続を閉じるよう変更。
- Self-hosted runner: `CCR_AUTO_MODE_ALLOW`、`CCR_AUTO_MODE_ENVIRONMENT`、`CCR_AUTO_MODE_SOFT_DENY` をセッションの環境に渡さなくなった。`CLAUDE_RUNNER_FETCH_SERVER_PROGRESS_CAP_MS` を追加。

### 2.1.294
- Stop／SubagentStop の `prompt` フックの判定を改善（早く止まりにくくなった）。

### 2.1.293
- Claude Haiku 5.5（`claude-haiku-5-5`）を追加。Anthropic API での既定の Haiku。1M コンテキスト、$0.10／$0.50 per Mtok（100K を超えるプロンプトは $0.50／$2.50）。
- `subagentStatusLine` のペイロードに `agentType` を追加。mods の `$.tool.register` に `isDeferred` を追加。
- 2.1.281 で入れた auto mode の拒否メッセージの変更を取り消し。
- claude.ai からのスキル同期の確認間隔を、使用中のセッションが無いときは約10分から約40分に変更。

### 2.1.292
- `claude plugin install` に `--marketplace <source>` を追加。
- Agent ツールに `effort` パラメータを追加。
- `CLAUDE_CODE_OVERLOADED_RETRY_BASE_DELAY_MS`。
- mods: `prompt.autocomplete` イベント、`$.model.complete` のプロンプトキャッシュ（`cache: true`）、`agent.spawn` に workflow エージェントを追加。
- **Security**: PreToolUse フックの承認と auto mode が、ネットワーク（UNC）パスからのファイル読み込みで許可の確認を飛ばしていた問題を修正。
- フック出力に含まれる `<system-reminder>` タグを、Claude に渡す前にエスケープするよう改善。
- ローカル（stdio）の MCP サーバーも、すべての環境（Bedrock、Vertex、Foundry を含む）でプロトコル 2026-07-28 を既定でネゴシエーションするよう変更。`MCP_PROTOCOL_NEGOTIATION=legacy` で元に戻せる。
- エージェント名の長さを最大256文字に制限。
- スケジュール実行と Run now で動くルーティンは、自分だけが見られる新しい artifact を承認なしで公開するよう変更。

### 2.1.290
- `claude attach <name>`、`claude logs <name>`（セッション名の一部で指定できる）。
- `/claude-api managed-agents-onboard <url>` と `/claude-api managed-agents-onboard <quickstart-name>`。
- mods: `turn.step` の `serverToolUses`、`tool.check` の `agentId` と `ceiling`、`ThemeKey`／`Color` 型、`claude plugin validate` の `gatingHooks`。
- `CLAUDE_CODE_DISABLE_NONESSENTIAL_TRAFFIC` で、起動時の接続の事前準備も省くよう変更。
- Claude in Chrome は、プロジェクトの設定ファイルからは有効化できなくなった（`--chrome`、`/chrome`、ユーザー設定で有効化する）。
- `pyright` は読み取り専用のコマンドとして扱われなくなり、実行前に確認が出る。`ps` も、確認が出る形が増えた。
- WebSearch の回数上限を、1時間あたり100回ずつ補充する方式に変更（`CLAUDE_CODE_WEB_SEARCH_REFILLS_PER_HOUR`。0 にすると補充しない）。以前は200回で終了していた。
- `CLAUDE_CODE_DISABLE_ATTACHMENTS` は、リポジトリの `.claude/settings.json` と `.claude/settings.local.json` からは設定できなくなった。
- `/code-review` の medium effort で、Opus 5.5 と Sonnet 5.5 でも整理（cleanup）の指摘と CLAUDE.md の規約に関する指摘を出すよう変更。
- Claude apps gateway が対応する PostgreSQL の最低バージョンを 14 から 11 に変更。
- cloud sessions の組み込みの `gh api` で、`GH_HOST`／`GH_REPO` に github.com 以外のホストを指定すると拒否されるよう変更。
- [Claude Tag] Slack で `!fast`／`!fast off` によって fast mode を切り替えられるようにした。

# CHANGELOG.md 2.1.302

## 要点

- 1版のみ（npm 公開日時 JST: 2.1.302 = 2026-10-17 01:48）。fingerprint は raw の CHANGELOG.md 全体（取得時点）の sha256。
- auto mode: クライアント側の分類器のモデルを選ぶ `CLAUDE_CODE_AUTO_MODE_MODEL` を追加（サーバー側 auto mode のモデルは変えない）。サーバー側分類器で会話が長すぎる場合は、全拒否でなくコンパクションする。
- **既定の変更**: サードパーティのプロバイダで、権限モード未指定の `claude -p` と Agent SDK は、telemetry 無効または新規インストールなら `default` で開始（`--permission-mode auto` なら auto のまま）。
- **サブエージェント**: fork subagent が `claude -p`、Agent SDK、デスクトップアプリ、VS Code でも既定オンに（ターミナルは元からオン）。デスクトップアプリと VS Code は、メイン会話のサブエージェントを常にバックグラウンドで実行する。
- Claude Design（claude.ai/design）の単体版が 2026-12-14 に終了する旨の通知を `/design-sync` と `/design-login` に追加。
- cloud sessions／routines／Claude Tag／Code Review に多数の修正と、routine の最終実行が始まらなかった理由のバナー追加。ほか、その他の修正が約 45 件。

## 具体的な値

- 環境変数（新規）: `CLAUDE_CODE_AUTO_MODE_MODEL`。既存: `CLAUDE_CODE_FORK_SUBAGENT=0` で fork subagent を無効化（`claude mcp serve` は常に提供しない）。
- 設定 UI: `/config` に `Idle compaction` の行（アイドル時コンパクションのオン／オフ。機能自体は 2.1.299 で追加）。
- fork subagent: `subagent_type: "fork"`。
- 変更: prompt hook と agent hook は、同一イベントで同時に最大 12 件まで実行し、残りは順番待ち。
- 変更: `← for agents` の案内は、セッション開始から 10 秒で非表示。
- Read ツール: 128 MB を超える画像ソースを拒否（以前は大きさに関わらず全体をメモリに読んでいた）。
- 変更: Claude in Chrome の指示の位置を system prompt 内で移し、新規会話が共有のプロンプトキャッシュを読めるようにした。
- 修正（キャッシュ関連）: セッション途中で追加したツールを ToolSearch やコンパクション後に再読込したときのプロンプトキャッシュミスを修正。
- 修正（MCP）: プロトコル 2026-07-28 をネゴシエーションするが `resultType`、`ttlMs`、`cacheScope` を返さないサーバーで、ツールが出ない／全呼び出しが失敗する問題。
- 修正（OTel）: auto mode 分類器のブロックで `tool_decision` イベントに `classifier_category` が欠けていた問題。`OTEL_LOGRECORD_ATTRIBUTE_COUNT_LIMIT` が低いと新属性が `tool_use_id`、`tool_source`、`tool_parameters` を押し出す問題。
- 修正（プロバイダ）: Vertex／Bedrock への途中切り替え後に "diagnostics: Extra inputs are not permitted" で失敗する問題。ゲートウェイが `anthropic/claude-opus-4-1` のように接頭辞付きで Opus 4／4.1 を名乗ると `/autocompact` と `/effort` が誤ったモデルに保存される問題。
- 修正（その他の主なもの）: コンパクション中に停止すると "Prompt is too long"。`claude plugin` 等が設定の書き込み完了前に終了する問題。reftable 形式の git で plugin marketplace が毎回 re-clone される問題。PowerShell ツールが plugin の `bin/` を見つけない問題。git 2.56 以降での worktree 作成拒否。Windows の exFAT／FAT32 での全書き込み拒否。プロンプト提案がクレジット課金のモデルで使用量を消費する問題（スキップに変更）。
- 改善: 多数のプラグインを有効にしたときの起動時間。バックグラウンドセッションをほかのフォルダから再開し LLM gateway が無い場合のメッセージ。
- 変更: 組織のポリシーで `/feedback` を無効にしているときのメッセージは GitHub issues を案内。
- `[Cloud sessions]`: routine のページに、直近の実行が始まらなかった理由のバナー（例: 組織の同時 cloud session の上限）を追加。"Rewind to here" が最新以外で失敗する問題を修正（self-hosted runner は v2.1.246 以降が必要）。routine の実行が、cloud session の異常停止後も Completed、開始前にアーカイブされると Cancelled と表示されていたのを failed に修正。途中で失敗した scheduled routine が 1 時間以上後に最初から再実行され、同じレポートを 2 回投稿しうる問題を修正。cloud session の費用と使用量が、新しいプロセスで再開すると 0 から数え直しになる問題を修正。PR の状態バー、diff 表示（リポジトリの改名・移動後）、別デバイスのメッセージ表示の修正。起動失敗時のエラーを "Connection lost"／"Server error" に。
- `[Self-hosted runner]`: reftable 形式の checkout を再利用するセッションで git fetch が "bad object refs/heads" で失敗する問題を修正。
- `[Remote Control]`: オフライン後にサブエージェントのペインが回り続ける問題を修正（"Remote Control is disconnected" と表示）。
- `[Claude Tag]`: 修正 — Slack で編集済み返信後も "is thinking…" が残る問題、コードブロック内 URL の山括弧、HEIC／SVG／TIFF／BMP 添付が届かない問題（ファイルとして届く）、役割で制限する組織で新しい channel manager が Slack で使えなくなる問題（manager ロールが Claude Tag in Slack も許可）、同一ホストの MCP サーバーのカスタムコネクタが 1 件にまとまる問題（サーバーごとに別コネクタ）、一時的な Slack 参照の停滞で DM を落とす問題（先に再試行）、Enterprise Grid の DM がワークスペース選択を無視する問題、チャンネルの月間利用上限の通知が organization owner と usage ページを案内、リンクが閉じの太字・斜体や全角句読点を巻き込む問題。改善 — 管理画面のリポジトリ検索（接続済み GitHub アカウント最大 100、GitHub App のインストールの 5,000 件超の private リポジトリも検索）、Add place と Add > Domain の即時表示。変更 — 管理設定で Claude のアクセスを 4 つのタブ（Bundles、Connectors、Skills and plugins、Channels）に整理。組織設定の Roles ページで Claude Tag の channel manager 用ロールを折りたたみ表示。
- `[Code Review]`: GitHub 接続のために離れた後、セットアップがリポジトリ選択の画面から再開するよう修正。
- `[VSCode]`: 3 件の修正（未閉じのコードブロック後の表示、クエリ付き URL の MCP サインイン、`@browser` バナー）。
- 上記以外の細かい修正・改善が約 15 件（ターミナル表示、agents view、Artifact の公開、`claude plugin details`、`claude remote-control --help`、`/design consent`／`/design revoke` の案内など）。

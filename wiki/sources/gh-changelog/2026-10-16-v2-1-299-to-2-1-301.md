# CHANGELOG.md 2.1.299〜2.1.301

## 要点

- 3版（npm 公開日時 JST: 2.1.299 = 10-14 09:23、2.1.300 = 10-14 23:27、2.1.301 = 10-15 23:34）。2.1.297 と 2.1.298 は CHANGELOG に見出しが無い（欠番かは確認できず）。
- **非互換の可能性**: MCP の allow ルールが、名前を指定したサーバーだけに効くようになった。`mcp__a` は `a__b` や `a_` というサーバーを許可しなくなり、`mcp__<server>__*` と正規化後の名前全体で書く必要がある。agent の `tools:` リストも同様（2.1.299）。
- MCP: クラウドセッションと Remote Control のコネクタは、フラグを取得しない環境でも 2026-07-28 を既定でネゴシエーションする（`MCP_PROTOCOL_NEGOTIATION=legacy` で無効）。Anthropic 第一者の MCP サーバーの説明は 4,096 字で切られなくなった（2.1.299）。
- コンテキスト／キャッシュ: ターミナルで**アイドル時のコンパクション**を追加（200K トークン超で約54分放置すると、1時間のプロンプトキャッシュが切れる前に圧縮）（2.1.299）。コンテキストの小さいモデルへ切り替えるときは、前のモデルが先に要約する（2.1.301）。OTel に `cache_creation_5m_tokens`／`cache_creation_1h_tokens`（2.1.300）。
- mods の API 追加・変更が多い: `prompt.change` フック、`virtualText`、`$.ui.view({ agentId })`、`rows`、`$.prompt.media`、`$.session.identity()` など。`.catch` と `$.env.set` の挙動変更あり。
- セキュリティ関連: サンドボックス内のコマンドが `--plugin-dir` に書き込めた問題、macOS の symlink 経由の denied path、`allowRead`／`allowWrite` の symlink 再確認、Windows の PreToolUse／PermissionRequest フックが Git for Windows 無しで fail open だった問題を修正（2.1.299）。ほか多数の細かい修正。

## 具体的な値

### 2.1.299
- 追加: `CLAUDE_CODE_DISABLE_FILE_MENTIONS`（`@` ファイルメンションで内容でなくパスだけ渡す）。
- 追加（アイドル時のコンパクション）: 200K+ トークンの会話が約54分アイドルなら、1時間のプロンプトキャッシュの失効前に圧縮。`CLAUDE_CODE_IDLE_COMPACT_MIN_TOKENS` で下限を変更、settings.json の `"idleCompaction": false` で無効。どちらも v2.1.290 以降が必要。
- 追加: `/effort`、`/fast`（agent view で新規セッションの初期値を設定。引数なしの `/model`、`/effort`、`/fast` はピッカーを開く）。`/usage` の警告（max effort、workflows、常時コンテキスト、大きなツール結果）。plan mode で bypass permissions が使える場合の一度きりの注意。
- 追加: `claude plugin eval` の `--disallow-tools` と `disallowed_tools` フィールド。`claude self-hosted-runner orchestrator` の `--shutdown-drain-sec`。
- 追加（Claude apps gateway）: `code` ポリシーの `env` に `CLAUDE_CODE_ATTRIBUTION_HEADER=0` で、Desktop の Code タブの attribution ブロックを無効にできる。gateway 経由の Claude Code セッションの attribution ブロックにも1フィールド追加。
- 追加（mods）: `$.prompt.media`（managed settings で入れた mod の `prompt.submit` が添付画像・文書のバイトを読める）、`$.session.identity()`（`forceLoginOrgUUID` が組織を列挙している場合に組織とメールが分かる）、`Text` の `size`／`weight`／`mono`／`tabular`、`Box` の間隔 `xs`〜`xl`（`bold` は `weight` に置き換えられ非推奨）、`skill.prompt` フックが受け取る情報（frontmatter、source、plugin 名、ファイルパス）、`session.append` の `queue` door。
- 変更（MCP・非互換の可能性）: MCP の allow ルールは名前を指したサーバーだけに届く。`mcp__a` は `a__b` や `a_` を許可しない。`mcp__<server>__*` と書く。agent の `tools:` リストはその MCP サーバーのツールだけを取り、`__` を含む名前は `mcp__<whole name>__*` と書く。関連修正: `mcp__<server>` の deny／ask ルールが、正規化後の名前に `__` を含むサーバーに効かなかった問題を修正。
- 変更（MCP）: cloud／Remote Control のコネクタは、フラグを取得しない環境で MCP プロトコル 2026-07-28 を既定にする。`MCP_PROTOCOL_NEGOTIATION=legacy` で無効。
- 変更（MCP）: `api.anthropic.com` の第一者 MCP サーバーのツール説明とサーバー指示は、4,096 字で切られず全文が Claude に届く。
- 変更（MCP）: claude.ai のコネクタプロキシと Anthropic ホストの MCP サーバーへのリクエスト、およびクラウド／self-hosted runner セッションの MCP プロキシへのリクエストは、HTTP リダイレクトに従わない。
- 変更: `UserPromptSubmit` フックは skill／カスタムスラッシュコマンドの展開より前に走る（ブロックすれば埋め込みシェルも止まる）。skill 自身の frontmatter の `UserPromptSubmit` フックは、skill を呼んだ次のプロンプトから走る。
- 変更: プラグインフックでブロックできる操作は、フックに渡せない、または答えを返せないとき、通さず拒否する。ネストは 28,000 段まで（workflow スクリプトは従来 100,000）。skill／コマンドで名前に不可視・方向変更文字、`<`、`>` を含むものは、改名まで提示しない。
- 変更: 終了時に表示する resume コマンドはセッション名でなく ID を使う。`/btw` の非対話セッションは 11 分で timeout。`turn.start` フックがサブエージェントとチームメイトのターンも受け取る（`e.agentId` で区別）。`claude plugin test` は 10 秒答えない `$` メソッドを失敗とする。`ui.render` の木の各 mod ルートに `part: { plugin }` が付く。`/ultrareview` のエラーが `git add .` を勧めなくなった。cyber safeguard の通知が Cyber Verification Program への申請を促さなくなった。
- 変更（Cowork クラウド）: auto mode では `PermissionRequest` フックがシェルコマンドやサブエージェントを承認できない。Claude in Chrome の分類器フラグは、auto mode 外では拒否でなく確認になる。
- セキュリティ関連の修正: サンドボックス内のコマンドが `--plugin-dir` に書き込める問題。macOS で denied path が symlink 経由なら実体の場所で読み書きできた問題。サンドボックスの `denyRead`／`allowRead` グロブの括弧・波括弧・バックスラッシュの解釈差。`allowRead`／`allowWrite` の起点ディレクトリが symlink に置き換わった場合の再確認。Windows で PreToolUse／PermissionRequest フックが Git for Windows 無しのとき fail open（今は拒否）。managed な permission rule・hook・組織 MCP ツール名の、ユーザー mod に対する強制を改善。`ANTHROPIC_BASE_URL` のサードパーティ gateway 用 API キーが、Anthropic への設定取得・フィーチャーフラグ等のリクエストに載っていた問題。`forceLoginOrgUUID`／`forceLoginMethod`（MDM・managed-settings ファイル）が server-managed settings に隠される問題。`__proto__` キーが黙って消され `tool.check` の guard を飛ばし得た問題。MCP サーバー名が `constructor`／`prototype` だと接続されなかった問題と、`constructor`／`toString` のツールが auto／bypass で確認を求めた問題。
- 修正（MCP）: HTTP MCP 接続が通知への返答の本文を閉じないサーバーで 30 秒固まる問題。ポリシーで拒否されるサーバーが、ポリシー確認前に接続される（headless／SDK）、または `claude mcp list`／`get` とサブエージェントで起動される問題（今は起動せず blocked と報告）。`enabledMcpjsonServers`／`disabledMcpjsonServers` が単一の文字列だと設定ファイルごと無視される問題。MCP OAuth のサインイン・更新・サインアウトが `headers`／`headersHelper` を送らない問題。空の `.mcp.json` を invalid と報告する問題。
- 修正（その他の主なもの）: `custom ANTHROPIC_BASE_URL` のストリームは 180 秒でなく 300 秒待つ。gateway 固有のモデル名で 200K 付近に "Prompt is too long · automatic compaction failed" になる問題。出力トークン上限で切れた返答が、非ストリーミングへのフォールバック後に黙って終わる問題。Read が UTF-16LE を壊す問題、Write が BOM を落とす問題と Windows-1252、Shift-JIS、GBK、UTF-16BE を黙って UTF-8 化する問題（今は拒否）。`/usage` などが 100% 超を表示する問題（anthropics/claude-code#92238）。
- 改善: WSL2 の `bwrap` エラー、Artifact の監視数 10 → 25、スキル名の "Unknown skill" エラーの案内、`/reload-skills` の説明（compaction 後にスキルを戻す方法）。
- 他: 細かい修正が多数（上記以外に約 100 件）。VSCode、Cloud sessions、Windows、Self-hosted runner、Claude Tag、Code Review の項目は2.1.300 側にもある。

### 2.1.300
- 追加（mods）: **`prompt.change` フック**（入力欄の文字が、タイプ以外の編集で変わったときに発火。履歴の呼び戻し、クリア、undo、プラグインによる入力）。`virtualText`（プロンプトの装飾。ドラフトにも送信にも入らない）、`$.ui.view({ agentId })`（`$.ui.view({})` で戻る）、`Text` の `dir`（右から左のテキスト）。`agent.spawn` フックで workflow エージェントの `prompt` と `model` を書き換え可能（従来は拒否のみ）。
- 追加: `cache_creation_5m_tokens` と `cache_creation_1h_tokens`（OpenTelemetry の `api_request` イベント）。OTel の GenAI セマンティック規約の属性（`gen_ai.provider.name`、`gen_ai.conversation.id`、`gen_ai.tool.name`、`error.type` など）をトレース span に追加。
- 追加: Claude Platform on AWS で `/advisor`（`/advisor`、`advisorModel`、`--advisor` で選ぶまで動かない。`CLAUDE_CODE_DISABLE_ADVISOR_TOOL=1` で無効）。
- 変更: `CLAUDE_CODE_PROVIDER_MANAGED_BY_HOST` のセッションは、`SSL_CERT_FILE` など CA バンドル、ツールプロキシ、git TLS、git config の変数を settings から無視（Claude Desktop 下ではプロジェクト設定のみ）。
- 変更: 終了時、停止を求めて 1.5 秒後も動く background コマンドを force-kill（fullscreen では残ることがあった）。
- 変更: api.anthropic.com への大きなリクエストは、テレメトリ無効でも gzip 圧縮。`CLAUDE_CODE_GZIP_REQUEST_BODIES=0` で無効。
- 変更: `forceLoginGatewayUrl` が Anthropic 運営の gateway を指す場合、Desktop の Code タブは managed settings を適用（起動時に到達可能であること）。`claude gateway` は、Desktop が gateway から使えない `desktop:` ポリシーキーがあると、警告でなくキー名を示して起動を止める。
- 変更: ローカルセッションの transcript が、各 API リクエストの system prompt、tools、パラメータも記録する（共有する transcript でリクエストを再現できる）。`/sandbox` のモード表示が "Sandbox commands"。hooks の `updatedInput`（PreToolUse、PermissionRequest）は Claude 自身の入力と同様に検証され、未知のキーは捨て、ツールが拒む入力は呼び出しを拒否。Cowork クラウドの `PermissionRequest` フックの allow 内 `setMode` は無視。
- 削除: `claude remote-control` の `--sandbox`／`--no-sandbox`（効果が無かった。指定するとエラー終了。`sandbox.enabled` を設定で指定）。
- 修正: `ENABLE_TOOL_SEARCH=auto` が会話の途中で無効になる問題。`forceLoginOrgUUID` に拒否された組織のトークンが残る問題。agent hook が `model` を無視する問題。MCP ツールの入力スキーマを API が拒否して毎ターン 400 になる問題（以後そのツールはパラメータ無しで送る）。compaction 後に接続した MCP サーバーのツールと指示が次のツール呼び出しまで伝わらない問題。git の reftable 形式のリポジトリで `--worktree` と diff が壊れる複数の問題。`--worktree` が誤ったコミットから始まる問題。headless／Agent SDK のセッション再開で compaction 後のメッセージや要約が失われる問題。
- [Claude Tag] Slack Connect チャンネル対応（Owner か Claude Tag admin が許可。既定はオフ）、コネクタ操作用の Allow once／Deny カード、Slack の音声クリップ対応。Slack Connect 化したチャンネルでも、admin が付けた access bundle が引き続き有効。
- [Claude Tag]（2.1.300 のその他）: canvas の削除、間違いの訂正を打ち消し線でなくその場の編集と "Edited" で行う、100 人超のチャンネルへは紹介メッセージ無しで参加、など。
- [Code Review] `@claude review` コメントが、GitHub 組織の所属が非公開の書き込み権限者の分だけ無視される問題を修正。一時停止コメントと月次支出上限コメントの案内先を修正（誘導先が変わった）。
- [VSCode] `claudeCode.attachSelection` 設定（エディタの選択テキストをメッセージに加えない）、fast mode が usage credits 切れ後もオンのままで拒否と再送を繰り返す問題の修正、ほか。
- 他: 細かい修正が多数（上記以外に約 60 件）。

### 2.1.301
- 追加: `CLAUDE_CODE_RETRY_WATCHDOG_MAX_USAGE_LIMIT_WAIT_MS`（無人 retry モード `CLAUDE_CODE_RETRY_WATCHDOG` で、リセットが遠い usage limit なら待たずに終了）。
- 追加: `claude-api` スキルに OpenTelemetry のトレース設定の案内（`ant` CLI で送信先設定）。vim モードの `%`（対応する括弧へ移動。d/c/y とも併用可）。
- 追加（mods）: `Input` の `rows`（複数行のテキスト欄。Enter で送信、Shift+Enter か Enter 前の円記号で改行）。
- 追加（OTel）: `tool_decision` イベントに `classifier_verdict` と `permission_mode`（auto mode の分類器の判定とルールの判定を区別）。`OTEL_LOG_TOOL_DETAILS=1` のとき `classifier_category`（分類器のブロックが一致した組み込みルール名）。
- 変更・改善（モデル切り替え）: コンテキストの小さいモデルへ切り替える際、会話が長すぎれば**前のモデルが先に要約**する。修正: 同じ切り替えで、確認なしに usage credits を使って要約することがあった問題。
- 変更（mods）: フックの `.catch` は、フックが throw するかタイムアウトしたときだけ走る（フック自身の呼び出しの下で起きたイベントは、`.catch` に問わずそのフックを飛ばす）。`$.env.set` は成功時 `{}`、書き込まなかったときは理由付きの `{ deny }` で解決する。
- 改善（mods）: VS Code と Desktop・モバイルでは、質問ダイアログの上の tree が Markdown と最大 48 行を持てる（ターミナルは平文 12 行のまま）。
- 修正: `fable`（と `best`）エイリアスが、最新の Fable が組織で使えないとき API でエラーになる問題（1回だけ前の Fable に再試行）。LLM gateway が要求と別のモデル名で返すため、会話が繰り返し圧縮される問題。`WorktreeCreate` フックが作った worktree を、未 push のコミットがあっても確認なしに終了時に削除する問題。Read がバイナリ（.xlsm、.parquet、.epub、.heic）をテキストで読む問題。スキルとコマンドの引数名が非常に多い・長いとき、先頭 64 個・各 64 字まで埋める（遅延対策）。
- 修正（Self-hosted runner）: managed settings が MCP サーバーを制限しているとき Slack 発のセッションがリポジトリを見つけられない問題（そうしたツールを止めるには `deniedMcpServers`）、ほか。
- 他: 細かい修正が多数（上記以外に約 40 件、VSCode の項目含む）。

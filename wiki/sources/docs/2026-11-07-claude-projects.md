# Let Claude coordinate ongoing work with Projects（2026-11-07 再取得・提供範囲のみ）

## 要点

- 段階は **public beta**。対象プランは **Pro、Max、Ultra**（前回 2026-10-10 の要約は Pro と Max のみ）。展開は段階的。
- Team と Enterprise では未提供（原文: "aren't offered on Team or Enterprise plans yet"）。
- 展開は、cloud sessions を使ったことがあり、claude.ai チャットや Cowork に既存 project が無いアカウントから始まった。サイドバーに無ければ **More** の下を探し、無ければ未到達で、waitlist がある。
- 「Create a project」前の確認事項にも「Pro, Max, or Ultra」とある。

## 具体的な値

- 原文（注記）: "Projects are in public beta on Pro, Max, and Ultra plans and rolling out gradually."
- project instructions は最大 16,000 文字。Remote Control で自分のコンピューターを使うには v2.1.280 以降。
- 使用量は他の Claude Code セッションと同じプラン上限に数える。

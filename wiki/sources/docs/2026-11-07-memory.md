# Memory（CLAUDE.md と auto memory）（2026-11-07 取得・auto memory の読み込み上限のみ）

## 要点

- 原文は `MEMORY.md` の先頭 200 行または先頭 25KB のどちらか先に達した方までを、毎会話の開始時に読み込むと述べる。それ以降は開始時には読まれない。
- 上限は `MEMORY.md` にだけ適用される。CLAUDE.md は、起動時に読まれるものは全文が読まれる（4 MiB 以下の場合。超えるファイルは読まれない）。
- 書き込み後に Claude Code が 200 行／25KB に対する長さを測り、上限に近いと短くするよう Claude に促し、超過するとエラーで索引の書き直しを促す。書き込み自体は成功する。
- auto memory はローカルマシン単位。ディレクトリは `~/.claude/projects/<project>/memory/`。

## 具体的な値

- 比較表の行: Loaded into「Every session (first 200 lines or 25KB)」。
- `MEMORY.md`: 索引。1 エントリ 1 行、詳細はトピックファイルへ。
- `autoMemoryEnabled`（`~/.claude/settings.json`）、`CLAUDE_CODE_DISABLE_AUTO_MEMORY=1`、`autoMemoryDirectory`（任意のスコープから読める）、`CLAUDE_CODE_PROJECT_DIR_NAME`。
- メモの `type`: `user`、`feedback`、`project`、`reference`。
- self-hosted environment のセッションは、既定で auto memory がオフ（Claude Tag セッションを除く）。
- サブエージェントのメモリは別（`sub-agents` の persistent memory）。メインの会話の auto memory はサブエージェントに読み込まれない（fork は例外）。

# Pricing（Claude API の価格）

## 要点

- Claude API の各モデルの単価の一覧（10-10 版の要約は [[sources/pricing/2026-10-10-pricing]]）。単価そのものは、Opus 5.5 を含め 10-10 版から変わっていない。
- **変更点: fast mode の段階**。ページは「Opus 5 と Opus 4.8 の fast mode は研究プレビュー」と書き、Opus 5.5 は研究プレビューから外れた（10-10 版は3モデルとも研究プレビュー）。platform-docs の 10-15 の内容と一致する。
- fast mode の価格は、200k 入力トークンを超えるリクエストを含む**コンテキスト全体**に掛かる。Claude API（first-party）で使え、Opus 5.5 は Claude in Microsoft Foundry（Azure ホスト）でも使える。Claude Platform on AWS とパートナー運営のクラウドでは使えない。
- Opus 5.5 と Sonnet 5.5 のキャッシュヒットは入力の0.05倍、Fable 5.1 と Mythos 5.1 は0.025倍、ほかは0.1倍。
- Haiku 5.5 は、プロンプトが 100,000 トークンを超えると高い単価になる（キャッシュの読み書きも長さに数える）。1M コンテキストの標準価格の対象から Haiku 5.5 は除かれる。

- limited availability（Mythos 5／5.1）: Cyber Verification Program などの認証プログラムで確認された組織だけが使える。
- Sonnet 5 の $2／$10 は、導入価格（2026-08-31 まで）だったものが通常価格になった。2026-09-01 の $3／$15 への引き上げは行われない。
- Claude 4.7 以降のモデルと Mythos Preview は新しいトークナイザーを使い、同じテキストで約30%多くトークンが出る。

fast mode（Claude Opus 5.5、Claude Opus 5、Claude Opus 4.8）:

| モデル | 入力 | 出力 |
| --- | --- | --- |
| Claude Opus 5.5 | $8 USD / MTok | $40 USD / MTok |
| Claude Opus 5 / Claude Opus 4.8 | $10 USD / MTok | $50 USD / MTok |

- fast mode の価格は 200k 入力トークン超のリクエストを含む全コンテキストに適用される。キャッシュの倍率とデータ所在地（`inference_geo`）の倍率は fast mode の価格に重ねて掛かる。Batch API では使えない。

Batch（入力／出力）: Fable 5.1、Mythos 5.1、Fable 5、Mythos 5 は $5／$25。Opus 5.5 は $2／$10。Opus 5、4.8、4.7、4.6、4.5 は $2.50／$12.50。Sonnet 5.5 と Sonnet 5 は $1／$5。Haiku 5.5 は $0.05／$0.25（100K 以下）と $0.25／$1.25（100K 超）。Haiku 4.5 は $0.50／$2.50。

その他:

- キャッシュの倍率: 5分書き込み 1.25倍、1時間書き込み 2倍、読み取り 0.1倍（上記の例外あり）。Batch やデータ所在地の倍率と重なる。
- `inference_geo: "us"` は、Claude 4.6 以降のモデルのすべての区分に1.1倍。Haiku 5.5 では 100K 超の高い単価にも掛かる。
- 1M コンテキスト: Claude 4.6 以降（Haiku 5.5 を除く）と Mythos Preview は標準単価のまま全域を使える。Haiku 5.5 は、1リクエストのプロンプトが 100,000 トークンを超えると、そのリクエストが高い単価になる。キャッシュヒットが一部でも同じ。以前のリクエストは当時の単価のまま。
- Claude Platform on AWS と Claude in Microsoft Foundry は CCU（Claude Consumption Units、1 CCU = $0.01）で請求される。Bedrock と Google Cloud は各社の価格を参照し、リージョン指定のエンドポイントはグローバルより10%高い。
- 他の節（ツール利用のトークン数、コード実行 1,550 無料時間／月、以降 $0.05／時間、Web 検索など）は、この取り込みでは詳しく読んでいない。

## 10-10 版からの変更点

- fast mode: Opus 5.5 が研究プレビューから外れた（Opus 5 と Opus 4.8 は研究プレビューのまま）。
- fast mode: 全コンテキストに料金が掛かる旨（200k 超の入力を含む）と、Opus 5.5 の Microsoft Foundry 対応が明記された（10-10 版の要約には無い。元のページに無かったのか、要約で拾わなかったのかは不明）。
- 表: 10-10 版の要約には、Fable 5、Mythos 5／5.1、Opus 4.8 以前、Sonnet 4.x、Haiku 3.5 などの行が無かった。今回は表の全行を載せた。これらが 10-10 版のページに既にあったかは、要約からは分からない（推測: 多くは既にあった）。
- 単価: 比較できる行（Fable 5.1、Opus 5.5、Opus 5、Sonnet 5.5、Sonnet 5、Haiku 5.5、Haiku 4.5、fast mode の Opus 5.5、Batch）に変更は無い。

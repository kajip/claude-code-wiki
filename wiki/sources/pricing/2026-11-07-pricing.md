# Pricing（Claude API の価格）

## 要点

- Claude API の各モデルの単価の一覧（前回 10-22 版の要約は [[sources/pricing/2026-10-22-pricing]]）。単価の表、キャッシュ倍率、fast mode の単価は 10-22 版から変わっていない。
- **変更点1: Claude Haiku 3.5 の行が表から消えた**（10-22 版では「retired, except on Google Cloud」付きで載っていた）。fast mode と Batch の表にも Haiku 3.5 は無い。
- **変更点2: fast mode の提供先に「Opus 5.5 は Claude Models on Google Cloud（Anthropic managed）でも使える」と明記された**。提供先は Claude API（first-party）、Claude Models on Google Cloud（Anthropic managed）、Claude in Microsoft Foundry（Azure ホスト）の3つ（Google Cloud と Foundry は Opus 5.5 のみ）。Claude Platform on AWS は、この節の提供先に載っていない。
- 退役モデルの注記が「Google Cloud」から「Claude Models on Google Cloud (Google managed)」に言い換えられた。パートナー運営（Google managed、Bedrock）と、Anthropic 運営（Claude Platform on AWS、Claude Models on Google Cloud (Anthropic managed)、Foundry）に分けて書かれている。
- fast mode の表の Opus 4.8 は「Opus 5 / Opus 4.8」の行に残り、研究プレビュー扱いのまま。非推奨・2026-11-30 削除の記載は価格ページに無い（platform-docs の fast mode ページにはある）。

| Claude Fable 5.1 | $10 | $12.50 | $20 | $0.25 | $50 |
| Claude Mythos 5.1（limited availability） | $10 | $12.50 | $20 | $0.25 | $50 |
| Claude Fable 5 | $10 | $12.50 | $20 | $1 | $50 |
| Claude Mythos 5（limited availability） | $10 | $12.50 | $20 | $1 | $50 |
| Claude Opus 5.5 | $4 | $5 | $8 | $0.20 | $20 |
| Claude Opus 5 | $5 | $6.25 | $10 | $0.50 | $25 |
| Claude Opus 4.8 / 4.7 / 4.6 / 4.5 | $5 | $6.25 | $10 | $0.50 | $25 |
| Claude Opus 4.1（retired, except on Claude Models on Google Cloud (Google managed) and Bedrock） | $15 | $18.75 | $30 | $1.50 | $75 |
| Claude Opus 4（retired, except on Claude Models on Google Cloud (Google managed)） | $15 | $18.75 | $30 | $1.50 | $75 |
| Claude Sonnet 5.5 | $2 | $2.50 | $4 | $0.10 | $10 |
| Claude Sonnet 5 | $2 | $2.50 | $4 | $0.20 | $10 |

- キャッシュヒットの倍率: Fable 5.1 と Mythos 5.1 は 0.025倍、Opus 5.5 と Sonnet 5.5 は 0.05倍、ほかは 0.1倍。
- Sonnet 5 の $2／$10 は導入価格（2026-08-31 まで）から通常価格になり、$3／$15 への引き上げは行われない（脚注）。

fast mode（Claude Opus 5.5、Claude Opus 5、Claude Opus 4.8）:

| モデル | 入力 | 出力 |
| --- | --- | --- |
| Claude Opus 5.5 | $8 USD / MTok | $40 USD / MTok |
| Claude Opus 5 / Claude Opus 4.8 | $10 USD / MTok | $50 USD / MTok |

- fast mode の提供先（原文の要旨）: Claude API（first-party）。Opus 5.5 は加えて Claude Models on Google Cloud (Anthropic managed) と、Azure ホストの Claude in Microsoft Foundry。
- 価格は 200k 入力トークン超を含む全コンテキストに適用。キャッシュとデータ所在地の倍率は重ねて掛かる。Batch API では使えない。
- `inference_geo` の 1.1倍は、Claude API（first-party）、Claude Platform on AWS、Claude Models on Google Cloud (Anthropic managed) に適用。Foundry は US Data Zone Standard デプロイのみ 1.1倍。Bedrock と Google managed は各社の独自のリージョン価格（原文）。
- Claude Managed Agents では、`model.speed` が `"fast"` のとき fast mode の割増価格が適用される（原文）。
- Claude Platform on AWS と Foundry は CCU（Claude Consumption Units、1 CCU = $0.01）で請求。
- Batch、1M コンテキスト、Haiku 5.5 の長いプロンプトの扱い等は 10-22 版の要約から変更を確認していない（Batch の表は全行を読み直していない）。

## 10-22 版からの変更点

- 表: Haiku 3.5（$0.80／$1／$1.60／$0.08／$4）の行が消えた。
- fast mode: Claude Models on Google Cloud (Anthropic managed) での Opus 5.5 の提供が価格ページに明記された。10-22 版は「パートナーのクラウドでは使えない」としていた。
- 退役モデルの注記の言い換え（上記）。
- 単価の変更は無い。

# Pricing（Claude API の価格）

## 要点

- Claude API の各モデルの単価の一覧。価格は、ここと claude.com/pricing を正とする。
- **Opus 5.5 と Sonnet 5.5 のキャッシュヒットは、入力単価の0.05倍**。Fable 5.1 と Mythos 5.1 は0.025倍、ほかのモデルは0.1倍。
- Haiku 5.5 は、プロンプトの長さで単価が変わる（100,000 トークンを境に高くなる）。キャッシュの読み書きも長さに数える。
- fast mode は**研究プレビュー**。対象は Opus 5.5、Opus 5、Opus 4.8。Claude API（first-party）だけで使え、Claude Platform on AWS とパートナーのクラウドでは使えない。
- Sonnet 5 の $2／$10 は、導入価格だったものが通常価格になった（2026-09-01 の値上げは行われない）。

## 具体的な値

| モデル | 入力 | 5分キャッシュ書き込み | 1時間キャッシュ書き込み | キャッシュヒット | 出力 |
| --- | --- | --- | --- | --- | --- |
| Claude Fable 5.1 | $10 | $12.50 | $20 | $0.25 | $50 |
| Claude Opus 5.5 | $4 | $5 | $8 | $0.20 | $20 |
| Claude Opus 5 | $5 | $6.25 | $10 | $0.50 | $25 |
| Claude Sonnet 5.5 | $2 | $2.50 | $4 | $0.10 | $10 |
| Claude Sonnet 5 | $2 | $2.50 | $4 | $0.20 | $10 |
| Claude Haiku 5.5（100K 以下） | $0.10 | $0.125 | $0.20 | $0.01 | $0.50 |
| Claude Haiku 5.5（100K 超） | $0.50 | $0.625 | $1 | $0.05 | $2.50 |
| Claude Haiku 4.5 | $1 | $1.25 | $2 | $0.10 | $5 |

（単位はすべて100万トークンあたりの USD）

- fast mode（Opus 5.5）: 入力 $8、出力 $40。キャッシュの倍率は fast mode の価格にかけて計算する。Batch API では使えない。
- Batch: Opus 5.5 は $2／$10、Sonnet 5.5 は $1／$5、Haiku 5.5（100K 以下）は $0.05／$0.25。
- `inference_geo` で US のみを指定すると、すべての区分が1.1倍（Claude 4.6 以降のモデル）。
- 1M コンテキストは、Claude 4.6 以降のモデル（Haiku 5.5 を除く）で通常の単価のまま使える。

# Claude Platform release notes（October 22 〜 October 30, 2026）

## 要点

- 10-22: Claude Models on Google Cloud（Anthropic managed）を開始。Anthropic が運用する Claude API を、顧客の Google Cloud プロジェクト経由で使う。アクセス制御は Google Cloud IAM、課金は Google Cloud Marketplace。ここでも Opus 5.5 の fast mode が使える。
- 10-23: Claude Tag API をベータで提供（Claude Enterprise 向け）。Slack のチャンネルとワークスペースにある Claude Tag の設定を読み書きできる。Claude Platform（Console）の組織では使えない。
- 10-28: first-party の Claude API で、Messages API と Token Counting API のリクエスト上限が 32 MB から 128 MB に上がった。
- 10-29: Usage and Cost Analytics API をベータで開始。従来の Usage and Cost API と、Claude Enterprise Analytics API の一部レポートは legacy になった（引き続きサポート）。
- 10-30: Opus 4.8 の fast mode を非推奨に。2026-11-30 に削除し、以降は `speed: "fast"` がエラーになる。fast mode を続けるには Opus 5.5 へ移行する。

## 具体的な値

- Claude Tag API（10-23、**ベータ**）: ベータヘッダー `experimental-claude-tag-2026-10-21`。エンドポイントは `/v1/organizations/claude_tag/`。Admin API キー（claude.ai で primary owner が作成）にスコープ `read:claude_tag` または `write:claude_tag` が必要。できること: Slack チャンネル／ワークスペースの設定の読み書き、チャンネルで有効な設定とその由来の表示、Access bundles の付与。ドキュメント: https://platform.claude.com/docs/en/manage-claude/claude-tag-api
- Usage and Cost Analytics API（10-29、**ベータ**）: ベータヘッダー `analytics-usage-cost-2026-08-24`。エンドポイントは `/v1/organizations/analytics/usage` と `/v1/organizations/analytics/cost`。Claude Console と Claude Enterprise の組織のトークン使用量と費用を返す。モデル、workspace、API キー、リクエストの背後のユーザー／サービスアカウントなどで絞り込み・グループ化できる。ドキュメント: https://platform.claude.com/docs/en/manage-claude/usage-cost-analytics-api
- legacy になったもの（10-29。すべて引き続きサポート）: Usage and Cost API、および Claude Enterprise Analytics API の `usage_report`、`cost_report`、`user_usage_report`、`user_cost_report`。移行手順はドキュメントの "Migrate from the Usage and Cost API" と "Migrate from the Claude Enterprise usage and cost reports"。
- リクエスト上限（10-28）: Messages API と Token Counting API は 32 MB → 128 MB（first-party Claude API）。
- Opus 4.8 の fast mode（10-30）: モデル `claude-opus-4-8` に `speed: "fast"` を付けた要求は、2026-11-30 の削除後にエラーを返す。移行先は Claude Opus 5.5（移行ガイド: `/docs/en/models/opus-5-5/migration-guide#migrating-from-claude-opus-4-8`）。
- Google Cloud（10-22）: ドキュメント `/docs/en/build-with-claude/claude-models-on-google-cloud/anthropic-managed`。

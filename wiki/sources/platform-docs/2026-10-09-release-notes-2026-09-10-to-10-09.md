# Claude Platform release notes（2026-09-10〜2026-10-09）

## 要点

- **新モデル**: Opus 5.5（09-22）、Sonnet 5.5（09-28）、Haiku 5.5（10-07）。3つとも 1M コンテキスト、最大出力 128k で、Claude API、Bedrock、Claude Platform on AWS、Google Cloud、Foundry で提供。
- **価格**: Sonnet 5.5 のキャッシュ読み取りを $0.20 から $0.10 に値下げした（入力単価の0.1倍から0.05倍へ。10-07）。Max と Team のプランに、毎月の API クレジットが付くようになった（10-07）。
- **非互換**: 5.5 世代では、どのモデルも強制の `tool_choice`（`any`／`tool`）が 400 になる。Opus 5.5 は thinking を無効にできない。Sonnet 5.5 で thinking を切るには `between_tools` を使う。Haiku 5.5 では、`budget_tokens`、サンプリングのパラメータ、prefill が 400 になる。
- **Managed Agents**: 権限ポリシー `auto`（09-10）、dynamic workflows（10-09、ベータ）。`web_fetch` は、セッションにすでに現れた URL しか取得しなくなった（10-07。データ持ち出しの対策）。
- **API の新機能**: 必要なときに会話を compact する機能（09-14、ベータ）、mid-conversation system message 内でのツール定義（09-22、ベータ）、cache diagnostics の GA（09-23）、Models API への項目の追加（`line`、`capabilities.thinking.types.disabled`、`capabilities.server_tools`）。
- **廃止の予告**: Claude Sonnet 4.5（`claude-sonnet-4-5-20250929`）は、Claude API では 2026-11-30 に提供終了の予定（09-30 に発表）。
- **拒否の課金**: 出力の前に拒否された場合のうち、`bio`、`frontier_llm`、`reasoning_extraction` の3分類で課金を再開した（09-24）。

## 具体的な値

### モデル
- Opus 5.5（`claude-opus-5-5`）: 1M コンテキスト（既定）、最大出力 128k。adaptive thinking は常に有効。$4／$20 per MTok。`thinking: {"type": "disabled"}` と `{"type": "enabled", ...}` は 400 になる。computer use は Claude API と Google Cloud では `computer_toolset_20260801` を使う（Bedrock では `computer_20251124` も使える）。fast mode は**研究プレビュー**として Claude API で使える（09-22）。
- Sonnet 5.5（`claude-sonnet-5-5`）: Sonnet 5 からの非互換は5点（`between_tools`、強制の `tool_choice`、thinking block のモデルへの結び付き、`computer_20251124`、advisor の組み合わせ）。thinking block は、作ったアカウントか、それに紐付くアカウントでしか効かない。別のアカウントから送ると、API はそのブロックを捨てたうえでリクエストを成功させる（09-28）。
- Haiku 5.5（`claude-haiku-5-5`）: 1M コンテキスト、最大出力 128k、adaptive thinking と effort に対応。Haiku 4.5 向けのコードで 400 になるもの: `budget_tokens`、`temperature`／`top_p`／`top_k`、prefill、`computer_20250124`。Bedrock では structured outputs を使えない。adaptive thinking が既定で有効（10-07）。
- 非推奨: `claude-sonnet-4-5-20250929` は、Claude API で 2026-11-30 に提供終了の予定。

### API
- compaction on demand: beta ヘッダー `compact-2026-09-04`、トップレベルの `compaction` パラメータ（09-14）。
- `input_transformations` の新しい種類 `thinking_mismatch_allowed`（beta `thinking-binding-controls-2026-08-01`）（09-14）。
- mid-conversation system message 内のツール定義: beta `inline-tools-2026-09-15`。MCP では `mcp-client-2026-09-15` も使う（09-22）。
- cache diagnostics は GA。`cache-diagnosis-2026-04-07` のヘッダーが不要になった（09-23）。
- Models API: `line`（10-01）、`capabilities.thinking.types.disabled`（10-05）、`capabilities.server_tools`（10-06）。
- SDK: Python 1.10.0、TypeScript 0.130.0、`ant` CLI 1.37.0 ほかで、Admin API が beta を外れ `client.organization` になった（09-30）。Python と TypeScript の SDK に、browser use と computer use のクラスがベータで入った（10-07）。

### Managed Agents
- 権限ポリシー `auto`。イベントの `evaluation` フィールドで、各呼び出しをどう判定したかが分かる（09-10）。
- `ant beta:sessions connect`（`ant` CLI 1.32.0。`--web` で Console の画面をローカルに開く）（09-10）。
- Dreams（研究プレビュー）が Opus 5.5、Fable 5.1、Sonnet 5.5 に対応（10-01）。
- networking が `limited` の環境では、`allowed_hosts` が `web_search` と `web_fetch` にも適用される。`web_fetch` がセッションに現れていない URL を取りに行くと、`url_not_in_prior_context` のエラーになる（10-07）。
- dynamic workflows（ベータ、`managed-agents-2026-04-01`）: `multiagent` を `{"type": "multiagent_20261001", "workflows": {"type": "enabled"}}` にする。進み具合は `workflow_run.*` イベントで追う（10-09）。

### その他
- 拒否の課金: 出力の前の拒否で課金されるのは、`bio`、`frontier_llm`、`reasoning_extraction` の3分類だけ。ほかの分類は引き続き課金されない（09-24）。
- Compliance API: Claude in Chrome のセッション（09-18、ベータ）、Microsoft 365 のローカルセッション（09-24、GA）、統合された Claude の体験のチャット（10-08、ベータ）。Activity Feed は、ファイル名などを返さなくなった（09-24）。

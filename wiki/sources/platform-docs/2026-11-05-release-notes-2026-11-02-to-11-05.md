# Claude Platform release notes（November 2 〜 November 5, 2026）

## 要点

- 11-02: Messages API の message threads をベータで提供。会話をサーバー側が保持するので、2回目以降のリクエストは新しいメッセージだけを送ればよい。長い会話やエージェントループで、リクエストが小さくなり time to first token も短くなる。
- 11-03: Claude Mythos 5、Claude Opus 4.7、Claude Sonnet 4.6 が生成するテキストに、Anthropic のテキスト透かし（text watermark）が付く。Sonnet 4.6 では `temperature`、`top_p`、`top_k` を既定値以外にした要求だと付かないことがある。
- 11-05: Claude Console で組織の IP allowlist をベータで設定できる。リストにないアドレスからの、対象サービスへのリクエストは拒否され、API キーが漏れても使える場所を限定できる。
- 11-05: Admin API で、Claude Enterprise（claude.ai）組織のメンバーをすべての場所でサインアウトさせられる（ベータ）。メンバーは組織に残り、再度サインインできる。

## 具体的な値

- message threads（11-02、**ベータ**）: ベータヘッダー `message-threads-2026-08-12`。thread は最後のリクエストの 5 分後に期限切れになり、最後の使用から最大 1 時間以内に削除される。提供先: Claude API、Claude Platform on AWS、Claude Models on Google Cloud（Anthropic managed）、Claude in Microsoft Foundry。ドキュメント: `/docs/en/build-with-claude/message-threads`
- text watermark（11-03）: 対象モデルは Claude Mythos 5、Claude Opus 4.7、Claude Sonnet 4.6。対象プラットフォームは Help Center の "How Claude marks AI-generated content"（support.claude.com/en/articles/16266773）に一覧がある。Sonnet 4.6 は `temperature`／`top_p`／`top_k` が非既定値のとき付かない可能性がある。ドキュメント: `/docs/en/build-with-claude/text-watermark`
- IP allowlist（11-05、**ベータ**）: IPv4・IPv6 のアドレスまたは CIDR 範囲を、1組織あたり最大 1,000 件。対象範囲と設定方法は `/docs/en/manage-claude/ip-allowlist`。
- Admin API のサインアウト（11-05、**ベータ**）: Claude Enterprise（claude.ai）組織のメンバーが対象。ベータヘッダーと、このリクエストでは終了しないものは `/docs/en/manage-claude/user-management#sign-a-member-out-everywhere`。API リファレンスは `/docs/en/api/beta/organization`。

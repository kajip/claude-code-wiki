# Claude Platform release notes（October 21, 2026）

前回（October 14、15、20）の続き。見出し 10-21 の1日分。fingerprint はリリースノートのページ全体の生データのもの。

## 要点

- 新しい API バージョン `2026-10-21` が出た。移行手順は Migrating to API version 2026-10-21 のページにある。
- クライアント SDK と `ant` CLI の新版が、既定でこの API バージョンを送る。新版には API バージョンと無関係の破壊的変更もあり、ライセンスが MIT から Apache 2.0 に変わった。
- user profiles に、Anthropic がエンドユーザーを制限または BAN したかを確認できる `enforcement_status` と `enforcement_actions` フィールドが加わった。
- Claude Code、Compliance API、Managed Agents に直接関わる項目は無かった。

## 具体的な値

- API バージョン: `2026-10-21`。ドキュメントは `api/migration-2026-10-21`（セクション `#upgrade`、`#sdk-changes`）。
- 新しい SDK／CLI の版: Python SDK 2.0.0、TypeScript SDK 1.0.0、C# SDK 13.0.0、Go SDK 2.0.0、Java SDK 3.0.0、PHP SDK 1.0.0、Ruby SDK 2.0.0、`ant` CLI 2.0.0。
- ライセンス: 新しい SDK と CLI は Apache 2.0（従来は MIT License）。
- user profiles: フィールド `enforcement_status`、`enforcement_actions`。制限または BAN が未解決のプロファイルは、[list](https://platform.claude.com/docs/en/api/user_profiles/list) に新しい `enforcement_status[]` フィルターを付けて探す。ドキュメントは `manage-claude/user-profiles`（節 "Check whether Anthropic has restricted or banned a profile"）。

# Fast mode（Claude API ドキュメント）

## 要点

- fast mode は同じモデルで出力を最大2.5倍速くするモードで、割増価格になる。リクエストに `speed: "fast"` を付けて使う。対象は Claude Opus 5.5（提供中）と、研究プレビューの Claude Opus 5 と Claude Opus 4.8。
- 対応プラットフォーム（Messages API）: Opus 5.5 は Claude API、Claude Models on Google Cloud (Anthropic managed)、Microsoft Foundry (hosted on Azure)。Opus 5 と Opus 4.8 は Claude API のみ（研究プレビュー）。Claude Platform on AWS と Bedrock は一覧に載っていない。
- 研究プレビューの Opus 5 と Opus 4.8 には `fast-mode-2026-02-01` ベータヘッダーが必要。Opus 5 を使うには担当者に連絡するかウェイトリストに参加する。
- Opus 4.8 の fast mode は非推奨で、2026-11-30 に削除される。以降 `claude-opus-4-8` への `speed: "fast"` はエラーを返す。移行先は Opus 5.5。
- Batch API と Priority Tier の契約とは併用できない。ZDR と HIPAA readiness の対象。

## 具体的な値

- `speed: "fast"`（Messages API）。Managed Agents ではエージェントの model オブジェクトに `{"id": "claude-opus-5-5", "speed": "fast"}`。
- 単価は Opus 5.5 が入力 $8／出力 $40、Opus 5 と Opus 4.8 が $10／$50（100万トークンあたり。[[sources/pricing/2026-11-07-pricing]] と同じ）。
- fast mode は専用のレート制限を持ち、超えると `429`（`retry-after` ヘッダー付き）。容量不足は `529`。レスポンスの `usage` に `speed`（`"fast"` か `"standard"`）が入る。
- SDK は fast mode の `429` を既定で最大2回自動再試行する。

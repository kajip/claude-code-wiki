# Claude Platform release notes（October 14、15、20, 2026）

前回（October 9）の続き。見出し 10-14、10-15、10-20 の3日分を1ページにまとめた。

## 要点

- 10-20: Inference hooks が Claude Enterprise 組織向けにベータを脱した。
- 10-15: Opus 5.5 の fast mode が研究プレビューを脱した。アクセス申請とベータヘッダーが不要になり、Start／Build／Scale の各 usage tier に既定のレート制限が付いた。Opus 5 と Opus 4.8 は研究プレビューのまま。
- 10-15: Opus 5.5 の fast mode が Claude in Microsoft Foundry（Azure ホスト）で使える。
- 10-15: Models API が `capabilities.thinking.types.between_tools` を返す。Compliance API は Instructions for Claude／Cowork の Global instructions を取得できる（Enterprise 向けベータ）。
- 10-14: OpenTelemetry export がベータで開始。Managed Agents の scheduled deployments が Claude Platform on AWS で利用可。

## 具体的な値

- Inference hooks: ドキュメントは `manage-claude/inference-hooks`。10-20 に Claude Enterprise 向けでベータ終了。
- Models API: `GET /v1/models` と `GET /v1/models/{model_id}` が `capabilities.thinking.types.between_tools` を報告する。これは `thinking: {type: "between_tools"}`（up-front thinking をオフにする）を受け付けるかどうかを示す。
- Compliance API: `GET /v1/compliance/organizations/{org_uuid}/user_preferences`。既存の Compliance Access Key と `read:compliance_user_data` スコープを使う。対象は claude.ai の **Instructions for Claude** と Cowork の **Global instructions**（Enterprise 向けベータ）。
- fast mode: Opus 5.5 は `fast-mode-2026-02-01` ベータヘッダーが不要（付けて送っても動く）。Opus 5 と Opus 4.8 は引き続き研究プレビューで、ヘッダーを送り続ける必要がある。
- OpenTelemetry export（ベータ）: Messages API のリクエストと Managed Agents のセッションを自前の観測基盤でトレースできる。SDK がスパンを出す言語は Python、TypeScript、C#、Go、Java、PHP、Ruby。API 側は Console で OpenTelemetry の destination を追加する。
- scheduled deployments（Managed Agents）: Claude Platform on AWS で利用可。

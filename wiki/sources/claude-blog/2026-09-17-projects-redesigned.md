# Projects redesigned: from folder to conversation

## 要点

- Projects を作り直した。コーディネーターのチャットが作業をスレッドに振り分け、各スレッドが作業を進める。
- **Claude Code でベータ**として提供。各スレッドは、専用のブランチとリポジトリのコピーを持つ Claude Code の cloud session。
- スレッドは今はクラウドで動く。ローカルのマシンで動かす機能は「近日」とされている。
- 共有メモリ、作業スタイルへの適応、ファイルと artifact のライブラリ、プロジェクトごとの使用量の表示がある。コーディネーターとスレッドで、それぞれモデルと effort を選べる。

## 具体的な値

- 最初のベータ: cloud session を使っていて、web とデスクトップに既存の project が無い一部の Pro／Max 契約者。翌週に Pro／Max の利用者へ広げる。その後、全プラン（Team／Enterprise を含む）へ広げる。
- アクセスの無い Pro／Max 利用者は waitlist に登録できる。

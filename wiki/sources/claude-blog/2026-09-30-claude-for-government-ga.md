# Claude for Government is now generally available

## 要点

- 連邦・州の機関向けの Claude for Government が一般提供（GA）になった。7月からパブリックベータだった。
- FedRAMP High の認可を受けた環境で提供する。
- **Claude Code CLI と Claude for Microsoft 365 は early access で順次提供**しており、GA ではない。
- 席の料金は無い。決まった単位で使用量を払い、超えてはならない上限が付く。

## 具体的な値

- 認可: FedRAMP High。
- デスクトップアプリは、機関の MDM で配布する。会話の履歴は機関が管理する端末に残る。
- 申し込み: claude.com/solutions/government。Claude Code CLI の early access は、公共部門のチームに申し込む。
